# Weekly Data Updates ETL

## Overview

The goal of this project is to implement a Weekly data updates ETL process. It should capture changes, which we can commit as a changelog that captures the added or removed tools. We should also capture any tool changes and classify them.

## Requirements

- ETL pipeline to run weekly data updates.
- Capture added and removed tools in the process.
- Capture tool modifications/changes and classify them.
- Commit these changes as a changelog.
